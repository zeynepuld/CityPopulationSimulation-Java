# City Population Simulation

Programlama Dillerinin Prensipleri dersi kapsamında Java ile geliştirdiğim konsol tabanlı nüfus simülasyonu ödevi.

## Proje Hakkında

Bu projede şehir, ilçe, mahalle ve kişi yapılarından oluşan bir nüfus simülasyonu geliştirdim. Kullanıcının belirlediği tur sayısı boyunca şehirlerdeki nüfus değişimini takip ettim.

Simülasyonda nüfus artışı, kişilerin yaşlarının ilerlemesi ve nüfusu belirli bir seviyeye ulaşan şehirlerin bölünmesi gibi işlemler yer alıyor. Oyunun sonunda seçilen şehrin detaylı bilgileri görüntüleniyor.

## Kullanılan Teknolojiler

- Java
- Eclipse IDE
- Java Faker

## Uygulanan Konular

- Nesne yönelimli programlama (OOP)
- Sınıf ve nesne tasarımı
- Modüler programlama
- Tek sorumluluk prensibi
- Koleksiyonlar ve nesneler arası ilişkiler
- Döngüler, koşullar ve simülasyon mantığı

## Projenin Amacı

Java ile nesne yönelimli programlama becerilerimi geliştirmek, birbiriyle ilişkili sınıfları kullanarak bir simülasyon oluşturmak ve daha modüler bir kod yapısı kurmak.
